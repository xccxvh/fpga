## 1. 先理清楚：有两条并行的线

之前的混乱来自这里——我在两条线之间来回跳，但没说明白它们是**两件事**：

```
线一：M1 主线（A 自己的活）
      把两份工程合并成一个"共同底座"
      目标：CPU 写 DDR → HDMI 显示出来
      需要重编 bitstream ⏱ 耗时长

线二：接口约定（解锁 B/C 的活）
      定义 CPU 可读的寄存器接口
      目标：B 能开工迁 RTL，C 能开工写驱动
      纯文档 + 小改 RTL，不用重编 ✅ 快
```

**线的优先级**：接口约定卡着 B 和 C 两个人。A 的活卡住会让全队停摆。
